# Обратная связь и локальная озвучка

## Сообщить об ошибке или предложить функцию

На ПК и Android откройте **Настройки → Обратная связь**. На телефоне это вкладка
в горизонтальном списке разделов мобильных настроек (список можно прокрутить).
Обе версии используют одну форму. Выберите тип обращения, заполните
название и описание. Для ошибки можно добавить шаги воспроизведения и ожидаемое
поведение. Черновик сохраняется на устройстве.

Кнопка **Продолжить на GitHub** открывает подготовленное обращение в
[Issues проекта](https://github.com/Lilislv/Setsuna/issues). Нужен аккаунт GitHub.
Проверьте текст, при необходимости приложите скриншоты и отправьте его на GitHub.
Обращения в этом публичном репозитории видны другим пользователям.

Для длинного обращения кнопка меняется на **Скопировать текст и открыть GitHub**:
вставьте скопированный текст в описание. Это позволяет избежать ограничения
длины URL. Приложение сообщает об открытии черновика, а факт отправки подтверждает
GitHub. Автоматически прикладываются только версия Setsuna и название ОС;
это можно отключить. Логи, настройки и история чтения не прикладываются.

В `.github/ISSUE_TEMPLATE` также есть шаблоны для создания обращений непосредственно
на GitHub. Для появления этих шаблонов на сайте они должны попасть в основную ветку.
Форма в приложении работает через параметры `title` и `body` без зависимости от шаблонов.

## Подключить android.db на ПК

1. Откройте **Настройки → Anki → Озвучка**.
2. Нажмите **Выбрать базу озвучки** и выберите файл `android.db`.
3. Выберите источник **Только локальная база** или **Локальная база, затем онлайн**.
4. При желании укажите предпочтительный источник, например `nhk16` или `shinmeikai8`.
5. Проверьте слово кнопкой **Прослушать пример**. Для карточек должно быть настроено поле
   озвучки Anki.

Локальная запись используется в словаре и в новых карточках. Уже созданные карточки
не изменяются. Выбранный клип плеера имеет приоритет над словарной озвучкой.

Если локальной записи нет, режим **Только локальная база** создаёт карточку без
озвучки и показывает сообщение. Режим **Локальная база, затем онлайн** обращается
к JapanesePod101. Ошибки открытия базы или сохранения записи в Anki показываются
пользователю и не маскируются отсутствием аудио.

Режим **Сначала онлайн, затем локальная база** проверяет JapanesePod101. Если записи
нет (включая звуковую заглушку сервиса) или запрос не удался, ищет запись в выбранном
файле. Проверенная онлайн-запись передаётся в Anki готовыми байтами, без повторного
скачивания. Если оба источника не нашли озвучку, карточка создаётся без неё с сообщением.
Настройки озвучки доступны и без подключения к Anki. Кнопка **Отключить** убирает
связь с выбранной базой, но не удаляет файл.

База остаётся внешним файлом: Setsuna открывает её только для чтения и извлекает
отдельные записи по слову и чтению. Переместив файл, выберите его заново.
В Anki передаётся сам аудиофайл, поэтому готовая карточка не зависит от пути к базе.
Формат содержит таблицы `entries` с метаданными и `android` с аудиоданными;
обычная база словаря вместо базы озвучки не подойдёт.

Выбор такой базы сейчас рассчитан на настольную версию. URI хранилища документов
Android (`content://`) требуют отдельной интеграции и пока не поддерживаются.

Описание проверок находится в [tests/README.md](../tests/README.md).
