Setsuna — десктоп-приложение для чтения японского текста.

## Функции

- Поиск слов как в Yomitan
- Импорт словарей Yomitan
- Интеграция с Anki
- Создание карточек в 1 клик
- Статистика чтения
- Онлайн- и локальная озвучка с выбором порядка поиска
- Сообщения об ошибках и предложения через GitHub Issues
- Синхронизация через Google Drive AppData
